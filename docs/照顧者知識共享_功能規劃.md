# 照顧者知識共享 — 功能規劃文件

> **功能定位**：讓照顧者（家屬）之間互相分享照護經驗、實用資訊與心情交流的社群功能
> **設計原則**：專業取向、輕量易用、自動化管理、不偏離主題

---

## 一、功能定位與價值

### 為什麼要做這個功能？

在照護場景中，家屬常常面臨三個困境：

1. **資訊孤立** — 不知道哪裡買尿布便宜、哪家醫院口碑好
2. **經驗匱乏** — 第一次照顧長輩，不知道翻身、餵藥等技巧
3. **心理壓力** — 長期照護容易累積情緒，需要同溫層抒發

現有的社群平台（LINE 群、臉書社團）雖然可以滿足這些需求，但資訊分散、難以搜尋、且沒有跟照護場景整合。**照顧者知識共享**把這個需求整合進 OmniCare，讓家屬不用切換 App 就能取得同溫層的支援。

### 跟專題主題的關聯

- **強化「家屬端」的功能深度** — 不只是監控長輩，還能參與照顧者社群
- **符合三方連結的核心理念** — 從「家庭內三方」擴展到「家庭間互助」
- **競品差異點** — Jubo、CareTogether、LingoWave 都沒有做社群功能

## 二、功能架構

### 三大內容分類

固定三個分類，**不開放使用者自建**（避免內容失控、分類混亂）

| 分類 | 內容範例 | 使用情境 |
|------|---------|---------|
| 📋 **照護技巧** | 翻身、餵藥、洗澡、傷口照護方法 | 新手家屬想學技巧 |
| 🛒 **用品資源** | 尿布哪裡便宜、輔具租借、藥局推薦 | 想省錢或找資源 |
| 💬 **經驗交流** | 心情抒發、面對困難的做法、感謝分享 | 需要同溫層支持 |

### 主要頁面

```
📱 照顧者知識共享（主頁）
  ├── 🔝 熱門文章區（觀看數前 5 名）
  ├── 🔍 搜尋列
  ├── 📂 分類切換（技巧 / 資源 / 交流）
  ├── 📋 文章列表（依觀看數排序）
  └── ✍️ 發文按鈕（右下角浮動）

📱 文章詳情頁
  ├── 標題、內容、發文者、時間
  ├── 觀看數、按讚數
  ├── 留言區
  ├── 檢舉按鈕
  └── 分享按鈕

📱 發文頁
  ├── 選擇分類
  ├── 標題
  ├── 內容
  ├── 上傳圖片（選填）
  └── AI 內容檢查 → 確認送出
```

## 三、核心功能設計

### 3-1. 搜尋功能

**設計重點**：讓使用者快速找到需要的資訊

**搜尋範圍**：
- 文章標題
- 文章內容
- 標籤（可自動從內容提取關鍵字）

**搜尋結果排序**：
1. 標題完全符合 > 標題部分符合 > 內容符合
2. 同樣符合度下，依觀看數排序

**進階功能**：
- 搜尋歷史紀錄（最近搜尋過的關鍵字）
- 熱門搜尋（例：「尿布」、「翻身技巧」、「南投藥局」）

### 3-2. 排序機制

**預設排序：觀看數由高到低**

理由：
- 觀看數高的通常是有價值的內容
- 新手一進來就能看到最有幫助的文章
- 鼓勵發文者提供高品質內容

**其他排序選項**（在畫面上方切換）：
- 📊 熱門（觀看數）— 預設
- 🕐 最新（發文時間）
- 💬 最多留言

### 3-3. 觀看數計算

**計算規則**：
- 同一使用者對同一文章 24 小時內只算一次
- 需真正點進文章詳情頁才計算（不含列表滑過）

**顯示方式**：
- 1,000 以下顯示實際數字（例：842）
- 1,000 以上顯示簡化格式（例：1.2K）

### 3-4. 熱門文章區

**顯示邏輯**：
- 過去 7 天內觀看數前 5 名的文章
- 用卡片橫向滑動呈現在主頁最上方

**視覺區別**：
- 熱門文章有「🔥 熱門」標籤
- 觀看數超過某個門檻（例：500）另加「✨ 精華」標籤

## 四、內容管理機制

### 4-1. 檢舉機制

**流程**：
1. 使用者看到不當內容，點文章右上角「⋯」→ 選擇「檢舉」
2. 選擇檢舉原因：
   - 廣告或垃圾訊息
   - 攻擊性言論
   - 醫療謠言或錯誤資訊
   - 涉及個人隱私
   - 其他（可自由填寫）
3. 系統記錄檢舉

**自動處理規則**：
- 被檢舉 **3 次** → 文章自動隱藏
- 被檢舉 **1 次** → 系統通知發文者「你的文章被檢舉了」，提示注意內容
- 隱藏後發文者可修改內容重新發布

**檢舉紀錄**：
- 存到資料庫，可以看出誰檢舉誰
- 惡意檢舉（例：對同一位使用者頻繁檢舉）可以在後續發現

### 4-2. 關鍵字過濾

**建立敏感字詞清單**：

三類關鍵字：

**A. 廣告類**
- 「加賴」、「加LINE」、「私訊優惠」、「代購」、「代辦」、「便宜賣」

**B. 攻擊類**
- 常見髒話清單（可參考網路上的中文敏感詞庫）
- 針對種族、國籍的攻擊性字眼（例：辱罵外籍看護的詞）

**C. 醫療高風險類**
- 「保證治好」、「一定痊癒」、「不用看醫生」、「偏方」、「祖傳秘方」

**觸發時機**：
- 使用者送出貼文時進行檢查
- 檢測到關鍵字 → 顯示警告訊息「內容包含不適合的字詞，請修改後再發布」
- 不直接封鎖，讓使用者自己修改

**技術實作**：

```javascript
// 建立敏感字詞清單（可以存在資料庫方便更新）
const 敏感詞 = ['加賴', '代購', '保證治好', ...];

function 檢查內容(內容) {
  const 觸發詞 = 敏感詞.filter(word => 內容.includes(word));
  if (觸發詞.length > 0) {
    return {
      通過: false,
      原因: `內容包含以下不適合字詞：${觸發詞.join('、')}`
    };
  }
  return { 通過: true };
}
```
